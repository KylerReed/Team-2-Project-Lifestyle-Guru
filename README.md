# Calorie Tracker - Team 2

## Lifestyle Guru

Lifestyle Guru is a browser-based calorie and nutrition tracking prototype developed by Team 2. The application allows users to manage a profile, set calorie and macronutrient goals, log meals, manage a Food Library, view nutrition progress, and review date-based meal history.

## Requirements

Python 3.10 or newer (compatible version)

## Installation Instructions

1. Extract the ZIP file.
2. Open a terminal in the extracted folder.
3. Run:

   python -m pip install -r requirements.txt

4. Run:

   python app.py

5. Open:

   http://127.0.0.1:5000

   in a browser.

## Database

The application uses the included local SQLite database:

`lifestyle_guru.db`

No external database server is required.

## Final Prototype Notes

The final prototype uses one active user profile and simplified account access for demonstration purposes. Some originally planned features, including multiple-profile support, were removed from the final project scope.
